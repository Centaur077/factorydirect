# Graphite & Amber — обновление дизайна

Изменена Docker-версия из factory-direct-main.zip.

- Графитовая тема по умолчанию и тёплая светлая тема по переключателю.
- Янтарные акценты, новая типографика, сетка и карточки.
- Локальные SVG-иллюстрации товаров; общий макет для неизвестных товаров.
- Декоративная анимация упаковки на главной с поддержкой prefers-reduced-motion.
- Адаптивные формы, поиск, страницы товаров и личного кабинета.

Новые стили: frontend/atelier.css. Иллюстрации: frontend/assets/.
Бэкенд, модели, админка и схема базы не изменены.

После замены frontend в существующем проекте:

```sh
docker compose up -d --build web
```

Сохраните свой .env. Не удаляйте том pgdata.

Проверено с работающим Docker API: загрузка каталога, поиск кофе, переход в карточку товара, загрузка SVG, отсутствие горизонтального переполнения на ширине 390 px и ошибок JS при этих действиях.
